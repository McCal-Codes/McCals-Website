# Sample .agents.md

This file is a lightweight example of repository-local agent definitions. Use it as a starting point for safe agents you can extend and approve in VS Code's Agent settings.

---

# planning-agent
name: planning-agent
description: "Generate step-by-step implementation plans. Read-only by default; must be handed off for file edits."
allowed_tools: [] # no tool access by default
rules:
  - "Return a numbered plan with clear checkpoints and estimated times"
  - "Do not modify files; produce a patch only after explicit user approval"

---

# git-hygiene
name: git-hygiene
description: "Run a pre-commit checklist: lint, test, and summarize changes."
allowed_tools:
  - git
  - shell
rules:
  - "Run 'git status --short' and show a summary"
  - "Run linters (if configured) and unit tests; report failures"
  - "Ask for explicit approval before running 'git commit' or modifying files"
run_command: "scripts/agents/git-hygiene.sh"
notes:
  - "This agent runs a repository-local script that summarizes the working tree, runs 'npm run lint' and 'npm test' if present, and exits non-zero on failures."
  - "The agent MUST ask for explicit approval before performing any write actions (commits, push, or file edits)."

---

# press-release-editor
name: press-release-editor
description: "Editing assistant tuned for press releases: tone, length, and boilerplate checks."
allowed_tools: []
rules:
  - "Suggest edits inline; never commit directly"
  - "Provide before/after examples and optional rewrite"

---

# reorganizing-agent
name: reorganizing-agent
description: "Scan repository structure and suggest file moves/renames to match workspace organization standards."
allowed_tools:
  - shell
rules:
  - "Run 'scripts/agents/reorganize-check.sh' to identify violations"
  - "Output suggestions for moving files to appropriate directories (manifest/, utils/, docs/, tests/, etc.)"
  - "MUST ask for explicit approval before executing any file moves or renames"
  - "Never move files without user confirmation"
run_command: "scripts/agents/reorganize-check.sh"
notes:
  - "This agent is read-only by default and reports violations of workspace organization standards."
  - "It checks for: scripts in root scripts/, widgets outside src/widgets/, docs outside docs/, test files outside tests/, and temporary/backup files."
  - "Future enhancement: add --fix flag to execute approved moves automatically."

# Usage notes
- Treat this file as documentation; user-approved agents must also be configured in your editor's Agent settings and tool approvals.
- Adjust `allowed_tools` tightly: prefer empty lists and explicit approval flows.
