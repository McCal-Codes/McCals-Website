# Nature Portfolio Widget v1.7 Enhancement Summary

## Overview
Enhanced the nature portfolio widget to display more photos and properly support landscape filtering without breaking existing functionality.

## Key Improvements

### 1. **Increased Photo Display (16 → 32 photos)**
- Changed default `data-panes` from 16 to 32
- Configurable range: 8-64 photos
- Widget now shows much more content by default

### 2. **Multiple Photos Per Collection (1 → 3 photos)**
- Enhanced round-robin algorithm to show up to 3 photos from each collection
- Uses multi-pass approach:
  - First pass: 1 photo from each collection
  - Second pass: 2nd photo from collections with more images
  - Third pass: 3rd photo from collections with even more images
- Distributes photos more evenly across collections

### 3. **Improved Landscape Filtering**
- Created `categorizeCollection()` function for intelligent category detection
- Checks both folder paths and tags for categorization
- Categories supported:
  - **Wildlife**: Birds, Mammals, Insects, Reptiles, Animals
  - **Landscapes**: Landscapes, Scenery, West Virginia, Mountains, Rivers, Forests
  - **Other**: Anything that doesn't fit above categories

### 4. **Dynamic Filter Tab Visibility**
- Filter tabs only show when content exists in that category
- Eliminates empty filter tabs
- "All" tab always visible
- Tab labels: "All", "Wildlife", "Landscapes", "Other"

### 5. **Better Category Detection**
- Examines folder structure: `Wildlife/Birds/` → Wildlife
- Examines folder structure: `Landscapes/West Virginia/` → Landscapes
- Falls back to tags if folder path unclear
- Case-insensitive matching for robustness

### Categorization Logic
```javascript
const categorizeCollection = (col) => {
  const folderPath = (col.folderPath || '').toLowerCase();
  const tags = (col.tags || []).map(t => t.toLowerCase());
  
  // Check folder path for Wildlife keywords
  if (folderPath.includes('wildlife') || folderPath.includes('birds') || ...) {
    return 'Wildlife';
  }
  
  // Check folder path for Landscape keywords
  if (folderPath.includes('landscape') || folderPath.includes('scenery') || ...) {
    return 'Landscapes';
  }
  
  // Fallback to tag-based detection
  // Return 'Other' if no match
};
```

### Filter Building
```javascript
// Count collections in each category
const categoryCounts = { Wildlife: 0, Landscapes: 0, Other: 0 };
state.manifest.collections.forEach(col => {
  const category = categorizeCollection(col);
  categoryCounts[category]++;
});

// Only show filters for categories with content
if (categoryCounts.Wildlife > 0) {
  filters.push({ key: 'Wildlife', label: 'Wildlife' });
}
if (categoryCounts.Landscapes > 0) {
  filters.push({ key: 'Landscapes', label: 'Landscapes' });
}
```

## Migration Path
To use v1.7 in production:
1. Test locally with `test-v1.7.0.html`
2. Copy `versions/v1.7-enhanced-display.html` to Squarespace Code Block
3. Adjust `data-panes` attribute if you want more/fewer photos (default: 32)
4. Add more photos to `src/images/Portfolios/Nature/` folders
5. Run `npm run manifest:generate` to update manifests
6. Widget will automatically detect and display new content
