# Test HTML Files

This directory contains organized test and debug HTML files for the McCal's Website project.

## Directory Structure

### `featured-portfolio/`
Test files specifically for the featured portfolio widget:
- `test-featured-debug.html` - Debug version of featured portfolio tests
- `test-featured-urls.html` - URL testing for featured portfolio
- `test-featured-v1.6.html` - Version 1.6 test file
- `test-featured-v15-working.html` - Working version 1.5 test
- `test-featured-widget-v15.html` - Widget version 1.5 test

### `debug/`
Debug and diagnostic files:
- `debug-featured-widget.html` - Featured widget debugging
- `debug-github-urls.html` - GitHub URL debugging
- `fresh-debug.html` - Fresh debug testing
- `widget-diagnostic.html` - General widget diagnostics

### `widgets/`
General widget test files:
- `widget-test-fresh.html` - Fresh widget testing
- `unified-portfolio-demo.html` - Unified portfolio demonstration

### `general/`
General test files:
- `path-test.html` - Path testing utilities
- `test-load-featured-items.html` - Featured items loading tests  
- `test-load-featured.html` - Featured content loading tests

### Pre-existing files
- `about-compressed.html` - Compressed about page test
- `about-page-complete.html` - Complete about page test
- `logo-test.html` - Logo testing

## Usage

These files are for development and testing purposes only. They are not deployed to production and serve as:
- Development debugging tools
- Widget behavior testing
- URL and path validation
- Performance testing
- Integration testing

## Note

Individual widgets also have their own test directories under `src/widgets/[widget-name]/tests/` for widget-specific testing.
