# Downloads Directory

This folder contains downloadable files for the McCal Media website.

## File Structure:
```
assets/
├── downloads/
│   ├── caleb-mccartney-resume.pdf          # Current resume/CV
│   ├── caleb-mccartney-cv-detailed.pdf     # Detailed academic CV
│   ├── portfolio-highlights.pdf            # Portfolio summary
│   └── media-kit.pdf                       # Press/media kit
└── images/
    └── logos/
        ├── new-york-post-logo.png
        ├── pittsburgh-magazine-logo.png
        ├── point-park-university-logo.png
        └── the-globe-logo.png
```

## GitHub Raw URLs:
When this repo is on GitHub, files can be accessed via:
`https://raw.githubusercontent.com/[username]/McCals-Website/main/assets/downloads/[filename]`

## Usage in Website:
- Resume downloads link to GitHub raw URLs
- Logo images link to GitHub raw URLs  
- Ensures reliable hosting and version control
- Easy to update files by pushing to repository

## File Requirements:
- **PDF files**: Keep under 10MB for fast downloads
- **Logo images**: PNG format, transparent backgrounds preferred
- **File naming**: Use lowercase, hyphens instead of spaces
