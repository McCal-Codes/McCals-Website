### Four Small Defects That Each Produced No Error

- **The booking endpoint validated one object and created another.** `api/schedule/book.js` parses the body with `bookingSchema` and reads `parsed.data` everywhere, including the conflict check, then passed the raw `req.body` to `createCalendarEvent`. So the event that got created was not the booking that was checked, and zod's bounds were bypassed on exactly the fields that end up in a calendar event: `locationDetail` is capped at 200 for that reason, and `durationMinutes` is added to a Date with `setMinutes`. One word.
- **The availability endpoint accepted any date span.** It checked the shape of `start` and `end` and never the distance between them, then walked one day at a time and asked Google for the whole window in a single `events.list`. `?start=2020-01-01&end=2999-12-31` was accepted, which is 357,938 iterations, at 60 requests a minute. Capped at 62 days, which covers the month the booking widget asks for with room to spare, and an end before the start is now refused.
- **The "Link copied" toast fired whether or not anything was copied.** Optional chaining meant an absent clipboard API produced no promise at all, and a rejected write went into an empty catch, so both cases still showed the message. Neither is hypothetical: the API is absent over plain http and the write is refused without permission. The toast now reports what happened.
- **`api/manifests/[type].js` crashed on inherited property names.** `TYPE_MAP` is a plain object literal, so `TYPE_MAP['constructor']` is inherited and truthy and passed the `if (!mapping)` guard; `path.resolve` then threw outside the `try`, crashing the function rather than answering 400. `Object.hasOwn` closes it.
- The tests for the last one were narrowed after checking them against the unfixed handler. Cases for `toString` and `valueOf` passed there, because the handler lowercases first and `tostring` is not an inherited property, so only all-lowercase names such as `constructor` and `__proto__` were ever reachable. Asserting the other two looked like coverage and tested nothing.
