Hello! This is a sample blog post used to exercise the new blog widget.

You can add posts by creating markdown files in `src/site/blog/posts/` and updating `src/site/blog/manifest.json`.

This demo supports likes and comments stored locally in the browser (localStorage). For team-wide persistence, integrate a backend or GitHub Issues.
