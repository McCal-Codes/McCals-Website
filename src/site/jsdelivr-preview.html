jsDelivr Widget Loader — Preview

This page demonstrates the simple, version-pinned loader used to fetch a widget HTML file from jsDelivr and inject it into the page. Replace the URL in the snippet to preview different widget versions.

Loader snippet

<div class="mccal-widget" data-src="JSDELIVR_URL_HERE"></div>
<script>
  (function(){
    var c = document.querySelector('.mccal-widget');
    if(!c) return;
    var s = c.getAttribute('data-src');
    if(!s) return;
    fetch(s,{mode:'cors'}).then(function(r){ if(!r.ok) throw new Error('Fetch failed'); return r.text(); }).then(function(html){ c.innerHTML = html; }).catch(function(){ /* fail closed */ });
  })();
</script>

Example — podcast feed widget (local v1.6)

Demo loading the local podcast feed widget (`src/widgets/podcast-feed/versions/v1.6.html`). This demonstrates inline rehydration of scripts and RSS-driven UI (may require CORS access for feed fetching).

Tip: Open this page in your dev server (npm run dev) to preview the widget locally. The loader is intentionally minimal — it expects the remote HTML to be self-contained (inline CSS/JS). Use `data-mode="iframe"` as a fallback if inline fetch/re-execution is blocked by CORS.
