Accessibility at McCal Media

Last updated

Accessibility Statement v1.2.0

McCal Media is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards.

Standards we follow

Our aim is conformance with WCAG 2.1 at level AA. We also monitor evolving guidance for WCAG 2.2.

  • Perceivable, Operable, Understandable, and Robust principles
  • Semantic HTML5 and ARIA where appropriate
  • Color-contrast targets of at least 4.5:1 for body text
  • Minimum 3:1 contrast for UI components and focus indicators

Scope & Coverage

This statement applies to our primary website and any sub-pages we control directly. Some embedded third-party tools may have their own accessibility constraints (see "Third-party content").

Feedback & Support

Keyboard Navigation

All interactive controls are reachable and operable with a keyboard. Try:

  • Tab / Shift + Tab to move focus forward and backward
  • Enter / Space to activate buttons and links
  • Esc to close menus and dialogs (including the mobile menu)
  • Arrow keys to navigate within menus or grouped controls

A "Skip to main content" link appears when focused to bypass repeated navigation.

Headings & Structure

Pages use a logical heading hierarchy (h1 → h2 → h3) and semantic HTML5 landmark roles (like <header>, <main>, <nav>, <footer>) for efficient navigation by assistive technologies.

Screen reader users can navigate by headings to quickly find content of interest.

Links

Links are descriptive out of context and avoid ambiguous text like "click here" or "read more". Where a link opens in a new window, we indicate this in text or with an accessible label.

Forms & Errors

Form inputs include associated <label> elements, clear instructions, and accessible error messages. Errors don't clear user input, and required fields are marked with both visual and programmatic indicators.

Text Alternatives

Non-decorative images include meaningful alt text. Purely decorative images are marked with empty alt attributes (alt="") or aria-hidden="true" so they're skipped by screen readers.

Color & Contrast

We target a minimum 4.5:1 contrast ratio for normal text and 3:1 for large text and UI components. Information never relies on color alone; there's always a secondary cue (text, icon, pattern, or state).

Our dark mode uses OLED-friendly true black (#000000) for energy efficiency on modern displays.

Audio & Video

Where we publish media, we provide captions and, when feasible, transcripts or audio descriptions. Videos do not auto-play with sound.

Motion & Animation

We respect the user's prefers-reduced-motion setting and minimize non-essential animation for those who opt in. Animations are limited to near-instant durations when reduced motion is enabled.

Language

The page language is identified in markup (lang="en") to help assistive technologies apply correct pronunciation rules. Language changes within content are marked appropriately.

Browser & Assistive Technology Support

We test with modern browsers (Chrome, Firefox, Safari, Edge) and common screen readers (NVDA, JAWS, VoiceOver) on desktop and mobile. If something doesn't work in your setup, please let us know.

Third-party Content

Some features (e.g., embeds, payment, or newsletter forms) are provided by third parties. We choose vendors with strong accessibility postures and raise issues when we find gaps.

Continuous Improvement

Accessibility is an ongoing effort. We conduct periodic automated testing with axe-core and manual reviews, triage issues, and track fixes. Major changes are reflected in this statement.

Recent Improvements (December 2025)

  • Fixed heading hierarchy across all pages (no skipped levels)
  • Applied lazy loading to 38 images across 30 HTML files
  • Enhanced ARIA labels and landmarks for screen reader navigation
  • Improved focus indicators (3px outline, 2px offset, WCAG AA compliant)
  • Validated all pages with axe-core (0 critical violations on main site)
