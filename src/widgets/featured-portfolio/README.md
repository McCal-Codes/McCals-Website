# Featured Portfolio Widget

**Current Version: v1.5-working** — Latest iteration with randomized cover images, masonry spacing refinements, and production-focused lightbox behavior.

## Active Version Policy
Only the latest working version is retained in `versions/`. Earlier iterations (v1.0–v1.4) have been moved to `src/widgets/_archived/legacy-widget-versions/featured-portfolio/` to reduce clutter.

## Features
- Randomized cover image selection (Fisher-Yates shuffle)
- Masonry layout with optimized column gaps
- Scrollable lightbox modal with immersive viewing
- Minimal gray accent styling for neutral presentation
- Debug metrics panel (optional via `?debug=true`)

## Usage
Embed the latest HTML file (`versions/v1.5-working.html`) directly into a Squarespace Code Block.

## Version History (Archived)
Earlier versions experimented with layout densities, initial shuffle strategies, and debug panel scaffolding. Consult the archive `INDEX.json` and widget CHANGELOG for details.
