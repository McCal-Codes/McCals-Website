CSS Playground Widget v1.2

This playground dynamically loads production widgets from the repository. Any changes to production widgets are automatically reflected here for testing.

v1.2 Feature: Direct production widget loading - always up-to-date with latest versions.

Production Widget Loader

How it works: Select a widget below to load its latest production version directly from src/widgets/. The playground automatically detects the newest version file and displays it.

Select Widget to Test

👆 Select a widget above to load its production version

Production Widget Paths

All widgets are loaded from: ../../[widget-name]/versions/[version].html

Available Widgets:
  • site-navigation/ - Nav bar with submenu (Squarespace injection)
  • podcast-feed/ - Podcast episodes with audio player
  • concert-portfolio/ - Concert photography galleries
  • event-portfolio/ - Event photography displays
  • photojournalism-portfolio/ - Journalism photo galleries
  • featured-portfolio/ - Curated portfolio highlights
  • portrait-portfolio/ - Portrait photography
  • site-footer/ - Glass design footer
  • about/ - About section with bio
  • hero-slideshow/ - Homepage hero sections
  • policies-legal/ - Legal documentation page

Direct File Testing

To test a widget directly without the loader, open the production file in your browser:

Example paths:
• file:///[path-to-repo]/src/widgets/podcast-feed/versions/v1.9.5.html
• file:///[path-to-repo]/src/widgets/concert-portfolio/versions/v4.7.html
• file:///[path-to-repo]/src/widgets/site-navigation/versions/v1.6.3-nav.html
