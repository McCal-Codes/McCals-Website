# Portfolio Manager

Simple portfolio management interface for McCal Media.

## Files

- `index.html` - Main portfolio manager (SIMPLE & WORKS)
- `portfolio-selector.html` - Advanced selector with status checks  
- `portfolio-access-simple.html` - Basic access page
- `system-diagnostic.html` - System status checker

## Usage

1. Open the manager in browser
2. Click "📋 Copy Path" for any portfolio
3. Press Windows + R  
4. Paste path and press Enter
5. Drop images in Band/Month Year folders
6. Auto-manifest watcher handles the rest
