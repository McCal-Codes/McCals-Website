Concert Widget Changelog

v4.8.0 - Modernized (Current)
  • Applied CSS custom properties from site-widgets.css v2.0.0 with fallbacks
  • Adopted BEM naming convention (mcc-concert__element--modifier)
  • Refactored to modern ES6+ JavaScript (const/let, arrow functions, async/await)
  • Integrated shared utility functions for better code organization
  • Enhanced accessibility with proper ARIA attributes and roles
  • Improved theme support (light/dark/system via data-theme)
  • All v4.7.x features and performance optimizations retained
v4.7.1 - Optional API
  • Optional API support: set data-api="on" to load manifest from /api/v1/manifests/concert
  • Graceful fallback to GitHub raw manifest on error
v4.7.0 - Artist Support (Spotify)
  • Added non-intrusive floating button to support artists with Spotify links
  • Automatic list of bands with "Open on Spotify" search links
  • Optional inline JSON map for embedded previews
  • Accessible keyboard/touch interactions
