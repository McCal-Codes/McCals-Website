Dynamic widget reloading for the dev site (dev.mcc-cal.com)

When you edit a widget file, changes appear on the dev site INSTANTLY without:
  ❌ Rebuilding the project
  ❌ Committing to Git  
  ❌ Pushing to GitHub
  ❌ Waiting for GitHub Actions
  ❌ Deploying to Squarespace

================================================================================
                            HOW TO USE IT (QUICK)
================================================================================

1. Start dev site:
   cd sites/dev.mcc-cal.com
   npm run dev
   
2. Open: http://localhost:3000/concerts (or any widget page)

3. Edit widget: src/widgets/concert-portfolio/versions/v4.7.1-api-optional.html

4. Reload ONE OF THREE WAYS:
   a) Press Ctrl+Shift+W (fastest)
   b) Click "🔄 Widget Reloader" button (top-right)
   c) Press F5 (traditional full refresh)

5. See changes instantly!

================================================================================
                            HOW IT WORKS
================================================================================

DEVELOPMENT MODE (localhost):
  Browser → Request /api/widgets/concert-portfolio/v4.7.1-api-optional.html
         → Next.js API Route [...slug].ts
         → Validates path for security
         → Reads from: src/widgets/concert-portfolio/versions/...
         → Returns fresh HTML (no cache)
         → WidgetEmbed injects into DOM
         → Scripts re-execute
         → Widget displays with your changes ✨

PRODUCTION MODE (deployed):
  Browser → Request https://raw.githubusercontent.com/McCal-Codes/.../v4.7.1-...
         → GitHub CDN
         → Returns cached, production-frozen HTML
         → WidgetEmbed injects into DOM
         → Scripts re-execute
         → Widget displays stable version

RELOAD METHODS:

  Method 1: Keyboard Shortcut (FASTEST ⚡)
    Ctrl+Shift+W (Windows/Linux)
    Cmd+Shift+W (macOS)
    Works from any page instantly

  Method 2: Click Button (EASIEST 🖱️)
    Look for "🔄 Widget Reloader" in top-right corner
    Shows widget name, version, and timestamp
    Dev-only (hides in production)

  Method 3: Full Page Refresh (TRADITIONAL 🔃)
    F5 (Windows/Linux)
    Cmd+R (macOS)
    Reloads entire page (slower but always works)

================================================================================
                            TROUBLESHOOTING
================================================================================

Q: Changes not appearing?
A: Verify you're on localhost, not production URL
   Check file path matches exactly (case-sensitive)
   Try Ctrl+Shift+W keyboard shortcut
   Check browser console for errors
   Try full page refresh (F5)

Q: "Widget not found" error?
A: Check file exists: src/widgets/[widget]/versions/[version].html
   Widget name must match exactly (case-sensitive)
   Version filename must include .html extension
   See WIDGET-HOT-RELOAD-GUIDE.md for troubleshooting

Q: Keyboard shortcut not working?
A: Try clicking the reload button instead
   Make sure you're on localhost
   Check browser console for JavaScript errors

Q: Port 3000 already in use?
A: Use different port: npm run dev -- -p 3001
   Or kill process: lsof -ti:3000 | xargs kill -9
