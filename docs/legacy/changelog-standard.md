# Changelog Standard — Vite Site (2026+)

This document defines the changelog and versioning standards for the Vite-based production site.

## Changelog Guidelines
- Use semantic versioning (MAJOR.MINOR.PATCH)
- Each release must have a dated changelog entry
- Summarize changes clearly (features, fixes, breaking changes)
- Link to related issues/PRs when possible

## Example Entry

```
## [1.2.0] — 2026-03-24
### Added
- New homepage hero section

### Fixed
- Accessibility bug in navigation

### Changed
- Updated footer links
```

> For legacy widget changelogs, see `../legacy/widget-changelog-standard.md`.
