# 2026 Dependency Audit & Upgrade Path

This document outlines the findings of the pre-upgrade audit for major dependencies in the McCals-Website repository.

## ESLint 8.57.1 → 9.x

- **Risk**: High (Breaking changes in config format).
- **Findings**:
  - The repository currently uses `.eslintrc.json`/`.js` patterns.
  - ESLint 9 requires `eslint.config.js` (Flat Config).
  - Several plugins (e.g., `eslint-plugin-react`) may need specific compatibility wrappers or updates.
- **Action Plan**:
  - Prepare `eslint.config.js` in a branch.
  - Use `@eslint/compat` if necessary for older plugins.
  - Update CI workflows to handle the new config.

## React 18.3.1 → 19.x

- **Risk**: High (Impacts Next.js and widget rendering logic).
- **Findings**:
  - `sites/dev.mcc-cal.com` is already on Next.js 15, but pinned to React 18.
  - `@types/react` is already at v19, creating a type/runtime mismatch.
  - React 19 introduces strict changes to ref handling and hydration.
- **Action Plan**:
  - Update `react` and `react-dom` to `^19.0.0` in both root and site `package.json`.
  - Perform a full build of `sites/dev.mcc-cal.com` to check for hydration errors.
  - Audit widgets using `jsdom` or React-like patterns (if any).

## Tailwind CSS 3.4.18 → 4.x

- **Risk**: Medium-High (CSS architecture changes).
- **Findings**:
  - V4 is a complete rewrite with high-performance engine.
  - Requires moving most configuration to CSS-first variables instead of `tailwind.config.js`.
- **Action Plan**:
  - Pilot v4 on a single widget or the dev site first.
  - Gradually migrate `site/styles.css` abstractions.

## Node.js 20.15.1 → 22.x LTS

- **Risk**: Low.
- **Findings**:
  - Most packages now recommend Node 20.17+.
  - Node 22 is the current LTS.
- **Action Plan**:
  - Update `.nvmrc` and CI/CD yaml files.
