Audit & Reports

This folder contains repository audit documents and reports generated by automated housekeeping tasks.

Contents
- `REPO-AUDIT-YYYY-MM-DD.md` — human-readable audit summary files.
- `reports/` — machine-readable and tool output reports (large-files, npm audit JSON).

Policy
- Keep audit documents in `docs/audit/` and reports in `docs/audit/reports/` for easy discovery.
- Reports may contain sensitive details (file sizes, dependency info). Review before publishing publicly.
