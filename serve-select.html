Serve Selector

Quickly open the project in either the development source (`src`) or the built output (`dist`). The server supports a per-request override using the ?root=src, ?root=dist, or ?root=site query parameter.

Open Dev (src) Open Prod (dist) Open Self-hosted (Next.js)
Tip: If you're running the server with --serve=dist or SERVE_TARGET=dist, clicking "Open Prod" will show files from the dist folder. If the build doesn't exist, the request will fall back to the default index.
Quick prerequisites: Node.js 18+ recommended. Network access to the npm registry is required to install dependencies. The canonical self-hosted site is the running Next.js server — run it from sites/self-hosted-nextjs and then use the button above to open the running app.
How to run the self-hosted Next.js app (canonical) 
cd sites/self-hosted-nextjs
npm run dev
# Next dev runs on port 3000 by default (script uses `next dev -p 3000`)
# Open http://localhost:3000/

# After a successful build
cd sites/self-hosted-nextjs
npm run start
# This runs `next start -p 3000` and serves the optimized production build.
# Open http://localhost:3000/

# This runs Next.js in server mode and is suitable for SSR/incremental rendering behavior that next export cannot provide.

# Note: Running the Next.js server is the recommended approach. Static exports are optional and depend on your Next.js configuration.

cd sites/self-hosted-nextjs
npm run build
# If your app/config supports it, you may export a static snapshot via `next export`:
# npx next export -o out
# This would write HTML/CSS/JS into sites/self-hosted-nextjs/out/ (only when supported)

# from repo root
PORT=3033 node dev-server.js
# open: http://localhost:3033/serve-select.html
