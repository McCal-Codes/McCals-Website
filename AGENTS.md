# AGENTS.md

## Learned User Preferences

- Prefers not to upgrade global npm (`npm install -g npm@…`) unless there is a concrete need; ad hoc major bumps are a poor default.
- When aligning editor guidance with the repo, treat `.claude/rules.md` as the primary in-repo rules source for Claude Code.
- Chose `/letting-me-go` as the canonical URL for the BFA thesis / "Letting Me Go" exhibition page on the public site.
- For on-site journalism and thesis photography, prefers AP-style photo captions and cutlines when writing or editing (datelines with abbreviated states, correct titles, consistent "Photo by" credit).
- Prefers to avoid em dashes in site copy (use commas, parentheses, or sentence breaks instead).
- For academic-style citations on the site, prefers APA author–date in text plus a References list; reserve footnotes for APA-allowed cases (e.g. explanatory notes, permissions).
- Prefers strict Git hygiene in every repo: keep commits small/scoped, separate generated artifacts from logic/config unless intentional, avoid committing local noise (e.g. `.cursor/` and temp files) and AI-generated artifacts by default, run verification before each commit, and use intent-first commit messages (`security:`, `ci:`, `docs:`, `content:`).
- Prefers clarification and scoping questions directly in chat instead of separate question dialogs.

## Learned Workspace Facts

- The actively maintained public app for this monorepo lives under `sites/mcc-cal-vite` (Vite + React; lazy routes in `App.tsx`, SEO via `usePageMeta`).
- **CI / Vercel parity:** GitHub `vercel-deployment-checks.yml` runs the public app build (`tsc -b` plus Vite), root ESLint, TypeScript check, and Vitest through `sites/mcc-cal-vite` `test:run`. Vercel project build command should stay aligned with `sites/mcc-cal-vite/vercel.json` (`npm run build`).
- **Dependencies:** Dependabot watches npm at repo root and at `sites/mcc-cal-vite`; review grouped dev-dependency PRs together.
- **Observability:** Production site uses Vercel Analytics and Speed Insights (`@vercel/analytics`, `@vercel/speed-insights`); expand only if you need deeper client error telemetry.
- New public routes should be added to `sites/mcc-cal-vite/src/config/public-routes.js` so routing and `sites/mcc-cal-vite/scripts/generate-sitemap.js` stay in sync.
- Legacy Squarespace-era widgets and related material are archived under `admin/_archived/`; CodeQL is configured to ignore that tree (see `.github/codeql/codeql-config.yml`).
- Blog slugs used for listings and cross-links are driven by `src/content/blog/blog-manifest.json` at the repo root.
- The journalism portfolio manifest at `src/images/Portfolios/Journalism/journalism-manifest.json` is generated by `scripts/manifest/generate-journalism-manifest-v2.js` (e.g. `node scripts/manifest/generate-journalism-manifest-v2.js --force` from the repo root); after changing portfolio images or `tags.json`, sync into the Vite app with `node scripts/sync-manifests.js` in `sites/mcc-cal-vite`.
- Portfolio and thesis artwork pages are grouped under the Projects navigation area (including the BFA thesis / exhibition route).
- BFA thesis exhibition still images (not journalism albums) live under `sites/mcc-cal-vite/public-vite/images/bfa-thesis/`; served as `/images/bfa-thesis/...`. Journalism portfolio images stay only under `src/images/Portfolios/Journalism/` and manifests — no "Letting Me Go" in those paths.
